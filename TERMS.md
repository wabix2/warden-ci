## 1. What Warden CI does

Warden CI is a GitHub App that scans pull requests for patterns associated with
AI-generated, unverifiable, or tampered code, and flags dependencies that show
signs of being newly published or low-adoption. It posts its findings as a
GitHub Check on the pull request. It does not block merges by default.
