# Warden CI Pro

## Product listing

**Name:** Warden CI Pro

**Price:** $19/month

**Short description:** Private-repository security scanning and verified remediation for GitHub pull requests.

**Description:**

Warden CI Pro is a practical security gate for teams shipping software on GitHub. It scans pull requests for dependency risk, leaked secrets, dangerous execution patterns, and package integrity signals, then makes the next action clear.

When a safe dependency upgrade is available, Warden guides the change through a reviewable workflow:

1. Finding detected
2. Fix proposed
3. Validation completed
4. Branch and commit created
5. Pull request opened
6. Fresh re-scan required
7. Fix verified only after the finding is gone

Creating a pull request never counts as fixing a vulnerability.

### Included

- Private-repository scanning
- Public-repository scanning
- GitHub Actions security gate
- Dependency and package-risk findings
- Secret and dangerous-execution detection
- Evidence-backed reports
- Tenant-safe dashboard access
- Auditable remediation states
- Safe dependency remediation proposals
- Human-review workflow for secrets and unsafe code
- Health, readiness, rate-limit, and operational safeguards

### Who it is for

Small engineering teams, maintainers, and independent developers who want useful security feedback in pull requests without deploying a large security platform.

### What Pro does not do

Warden does not scrape contacts, discover people for outreach, or send unsolicited email. AI-assisted drafts, when enabled, use only contacts and context supplied by the account owner. Sending requires consent and explicit human approval.

### Setup

1. Subscribe to Warden CI Pro.
2. Install the Warden GitHub App.
3. Add the Warden security gate workflow to the repositories you want to protect.
4. Configure the required Warden token and webhook settings.
5. Open a pull request and review the security gate result.

### Support

Support is provided through the Warden support channel. Include the repository, workflow run URL, and finding identifier when reporting an issue. Never include secrets or access tokens in a support request.

### Refunds

If Warden CI Pro does not work for your repository after following the setup guide, contact support with the workflow run URL and we will help troubleshoot or process an eligible refund according to the published refund policy.
